TABLESIDE GROWTH — LOCAL FINAL CANDIDATE v2

THIS VERSION REQUIRES NO PYTHON AND NO LOOSE JAVASCRIPT FILES.

OPEN
1. Extract the ZIP.
2. Double-click index.html.
3. Use Edge or Chrome.

WHAT IT CAN DO LOCALLY
- Prospect database
- Prospect statuses
- Public web research shortcut
- Task queue
- Start / Pause / Stop / Emergency Stop
- Daily task limit
- Automatic local outreach package generation
- Human approval queue
- Gmail compose handoff
- Follow-up scheduling/reminders while the page is open
- Manual reply tracking
- Client conversion tracking
- Revenue tracking
- 30-day client deliverable generation
- Activity history
- Data export/backups

WHAT IT DOES NOT DO
- It does not read Gmail automatically.
- It does not send Gmail automatically.
- It does not log into Instagram.
- It does not send Instagram DMs.
- It does not accept/move/refund payments.
- It does not spend money.
- It does not discover businesses automatically from Google Maps.
- It does not keep running after the page/app is closed.

DATA
Working data is stored in browser Local Storage for the current browser profile.
Use Export Data regularly to create a backup JSON file.

CONTROL
STOP = stops the local worker.
EMERGENCY STOP = stops it from taking new queued tasks.
Closing the page/window stops the local worker.
No financial or outbound-account action is autonomous in this build.

NEXT / EXTERNAL INTEGRATIONS
The remaining steps are not more local UI work. They require official external services:
- Gmail OAuth/API for inbox sync and draft creation
- hosted HTTPS app if you want installable PWA behavior
- optional controlled business-data/research provider
- optional payment-provider read-only/payment-status integration

Do not provide raw passwords, recovery codes, cookies, or card details to the app.
